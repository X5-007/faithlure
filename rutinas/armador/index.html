Rutina cifrada y lista

index.html es el único archivo que va a GitHub. Dentro lleva la rutina cifrada.

  1. En tu computadora crea una carpeta llamada y mete dentro el index.html que acabas de descargar.
  2. En github.com abre tu repositorio y entra a la carpeta rutinas.
  3. Add file → Upload files y arrastra la carpeta completa (no el archivo suelto: así GitHub respeta el nombre de la carpeta).
  4. Commit changes. En menos de un minuto el link funciona.
El respaldo NO se sube a GitHub.

El archivo tiene la clave sin cifrar. Guárdalo en tu computadora: es lo que te deja volver a editar esta rutina. Si lo subes al repositorio, el cifrado deja de servir de nada.

¿Perdiste el respaldo? Usa «Abrir desde link» y pega la URL completa del alumno: de ahí se recupera la rutina para editarla.

Guardar tus ejercicios en el sitio

Así dejan de vivir solo en este navegador y los tienes desde cualquier computadora.

  1. En github.com abre tu repositorio y entra a rutinas.
  2. Haz clic en el archivo ejercicios.js y luego en el lápiz (Edit).
  3. Selecciona todo el contenido y bórralo.
  4. Abre el ejercicios.js que descargaste con el Bloc de notas, copia todo y pégalo ahí.
  5. Commit changes.

Al recargar el armador, tus ejercicios ya vendrán del archivo y la lista local se limpia sola. No se duplican.
