Rutina cifrada y lista

index.html es el único archivo que va a GitHub. Dentro lleva la rutina cifrada.

  1. En github.com abre tu repositorio y entra a la carpeta rutinas.
  2. Add file → Upload files.
  3. Arrastra index.html y escribe la ruta antes del nombre.
  4. Commit changes. En menos de un minuto el link funciona.
El respaldo NO se sube a GitHub.

El archivo tiene la clave sin cifrar. Guárdalo en tu computadora: es lo que te deja volver a editar esta rutina. Si lo subes al repositorio, el cifrado deja de servir de nada.

¿Perdiste el respaldo? Usa «Abrir desde link» y pega la URL completa del alumno: de ahí se recupera la rutina para editarla.
